# Synapta Connect panel

The React panel is built with Vite and Tailwind CSS. Build it with `npm ci` and `npm run build`. Vite writes production files to `dist/` with the base path `/synaptaconnect/`. Fonts and JavaScript are served locally.

Run `synapta-connect.exe panel` to open the app. The browser exchanges its one-time code for an in-memory session. The Network page controls browser channels and all three ports. The install guide generates the matching PowerShell command.

See [release and deployment](../docs/RELEASE.md) for the two signed update feeds and HTTPS setup.
