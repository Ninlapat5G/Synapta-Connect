    ติดตั้งบน Windows

    ตั้งค่าบริการแล้วคัดลอกคำสั่งไปใช้ใน PowerShell

    ตัวเลือกบริการ

    Agent ใช้บัญชี NT SERVICE\SynaptaConnect การรันคำสั่งและเข้าถึงไฟล์ขึ้นอยู่กับสิทธิ์ของบัญชีนี้

    ใช้ github:OWNER/REPO หรือ URL แบบ HTTPS ที่ลงท้ายด้วย / กรอกชื่อเครื่อง\ผู้ใช้ หากยกสิทธิ์ด้วยบัญชีผู้ดูแลคนละบัญชี

    คำสั่งสำหรับ PowerShell
