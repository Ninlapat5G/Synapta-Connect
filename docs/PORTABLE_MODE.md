# Synapta Connect Portable

อัปเดตขอบเขตตามที่ตกลงกันวันที่ 2026-11-26 ต่อยอดจาก decisions #15 ของ Synapta Device Protocol

## ต้องการอะไร

ดับเบิลคลิกไฟล์ `.exe` บนเครื่อง Windows แล้วใช้ชื่อเครื่องกับ OTP ที่แสดงเพื่อจับคู่จากแอปของ Synapta
ใช้ API ของ Connect สำหรับดูจอ ควบคุมเมาส์และคีย์บอร์ด เปิดเทอร์มินัล รันคำสั่ง เรียกดูและรับส่งไฟล์

## ขอบเขตที่เจ้าของเลือกแล้ว

- อยู่ใน **repo นี้**: เป็นโหมดพกพาของ Connect ไม่ใช่ runtime ใหม่ใน SDP
  ใช้การจับคู่ด้วย OTP/SPAKE2, mTLS และ tool `connect_*` ที่มีอยู่แล้ว
- **เครือข่าย**: รับ TCP และ UDP บนทุกอะแดปเตอร์ IPv4 ที่ Windows เปิดใช้งาน รวมถึง Radmin VPN, Tailscale และเครือข่ายเสมือนอื่น โดยไฟร์วอลล์และการกำหนดเส้นทางของเครื่องเป็นตัวกำหนดว่าใครเข้าถึงพอร์ตได้ Portable เชื่อมต่อโดยตรงและใช้ OTP กับ mTLS ในการยืนยันตัวตน
- **OS**: รุ่นแรกใช้หน้าต่าง Win32 และใช้โมดูลจับจอกับส่ง input ของ Connect เดิม

## การเริ่มและจบเซสชัน

- เปิด `synapta-connect-portable.exe` ภายใต้สิทธิ์ Windows ของคนที่เปิด ผู้ใช้ที่ต้องการสิทธิ์แอดมินเปิดด้วย **Run as administrator** จาก Windows
- Windows เลือกพอร์ต TCP ที่ว่าง ส่วนการค้นหาใช้ UDP `52403` เพื่อให้รันพร้อม Connect รุ่นติดตั้งได้ หาก Windows Firewall ถาม ให้คนหน้าเครื่องเลือกอนุญาตตามนโยบายของเครื่อง
- Portable ถือคู่กุญแจและรายการจับคู่ในหน่วยความจำ ฝั่งควบคุมจับคู่ด้วย SPAKE2 แล้วเปิด WebSocket ที่ยืนยันตัวด้วย mTLS ตลอดเซสชัน เพื่อให้ HTTP, WebSocket ของเทอร์มินัล และการถ่ายโอนไฟล์เดิมทำงานได้
- เซสชันใช้งานได้ตราบใดที่แอปฝั่งควบคุมยังเชื่อมต่อ หากฝั่งนั้นตัดการเชื่อมต่อ Portable จะเพิกถอนการจับคู่และแสดง OTP ใหม่ หากปิด Portable พอร์ตและเซสชันจะปิดตาม
- โปรโตคอลเซสชันใช้ร่วมกับแอปของ Synapta ที่รองรับได้ ฝั่ง SynaptaCode ใช้เครื่องมือ `connect_*` เดิมและเก็บอุปกรณ์ Portable ในหน่วยความจำตลอดการเชื่อมต่อ

## ข้อจำกัดที่ต้องบอกผู้ใช้

- เมื่อเปิด Portable ด้วยสิทธิ์ปกติ Windows จำกัด input ไปยังหน้าต่างที่ยกระดับสิทธิ์ หน้าจอ UAC ที่ใช้ Secure Desktop จัดการจากหน้าเครื่อง
- exe ที่ไม่ได้เซ็นจะโดน SmartScreen เตือน และแอนติไวรัสบางตัวอาจจับว่าเป็นโปรแกรมรีโมต

## ตรวจสอบก่อนแจก

ใช้ `SECURITY_REVIEW.md` และ `TEST_PLAN.md` ของ Connect รวมถึงทดสอบเปิดไฟล์จาก Explorer ด้วยบัญชีปกติและบัญชี elevated ทดสอบการค้นหาและจับคู่ผ่าน LAN และ VPN แล้วตรวจว่าปิดจากทั้งสองฝั่งได้

โค้ดของตัว Portable อยู่ใน `portable/src/` และทรัพยากรของ Windows อยู่ใน `portable/assets/` โดยใช้ Rust backend ร่วมกับ Connect

Portable ใช้โมดูล SDP OTA ร่วมกับ Connect รุ่นติดตั้ง ตั้งค่าโมดูลบนเครื่องอัปโหลดได้ตาม [คู่มือ SDP OTA](SDP_OTA.md) แล้วจับคู่ Portable จากแอปฝั่งควบคุมตามปกติ

บน Windows ให้ build Web Panel ตามขั้นตอนของ Connect ก่อน แล้วรัน `cargo build --release --locked --bin synapta-connect-portable` จากโฟลเดอร์ `backend` ไฟล์ที่ได้คือ `backend/target/release/synapta-connect-portable.exe` เก็บไฟล์พร้อมรันไว้ใน `portable/bin/` ได้ โฟลเดอร์นี้ใช้เก็บไฟล์ build บนเครื่องและอยู่ใน `.gitignore`
